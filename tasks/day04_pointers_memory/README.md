# Day 04: Pointers, Memory & Heap Allocation

## Concepts Covered
- Memory addresses and the `&` operator
- Dereferencing with `*`
- Pointer arithmetic
- Heap allocation using `new` and `delete`
- Dynamic arrays with `new[]` and `delete[]`
- Preventing memory leaks and dangling pointers

## Exercise
Dynamically allocate an array on the heap, perform pointer arithmetic traversal, reverse it in-place using two-pointer technique, and properly deallocate memory.
