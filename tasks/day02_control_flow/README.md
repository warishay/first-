# Day 02: Control Flow & Logic

## Concepts Covered
- Conditional branching: `if`, `else if`, `else`, and ternary operator `? :`
- Multi-way selection: `switch-case`
- Loops: `for`, `while`, `do-while`, and range-based `for`
- Loop control: `break` and `continue`

## Exercise
Implement a prime number sieve, Fibonacci sequence generator, and grade classification logic.
