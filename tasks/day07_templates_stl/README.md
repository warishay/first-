# Day 07: Templates & The Standard Template Library (STL)

## Concepts Covered
- Function templates and class templates
- STL Sequence Containers: `std::vector`
- STL Associative Containers: `std::unordered_map`
- STL Algorithms: `std::sort`, `std::accumulate`, `std::count_if`
- Modern C++ Lambdas

## Exercise
Implement a generic stack data structure using templates and perform word frequency frequency analysis using STL `unordered_map` and lambdas.
