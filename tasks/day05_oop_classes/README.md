# Day 05: Object-Oriented Programming (OOP) Fundamentals

## Concepts Covered
- Class definition, member variables, and member functions
- Access specifiers (`private`, `public`) and encapsulation
- Constructors (Default and Parameterized with member initializer lists)
- Destructors (`~ClassName`)
- `const` member functions

## Exercise
Implement an encapsulated `BankAccount` class with audit logging, secure balance management, and transaction limits.
